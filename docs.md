# Документация Graph-extention

## Что находится в папке

* В этой папке находятся все файлы, необходимые для расширения.
* `package.json` - файл манифеста, в котором объявляются расширение и команда.
  * Расширение регистрирует команду `graph-extension.ProjectGraphMaker` и задает ее название. С этой информацией VS Code может показать команду в палитре команд. Для этого плагин еще не нужно загружать.
* `src/extension.ts` - главный файл с реализацией команды.
  * Файл экспортирует две функции: `activate`, которая вызывается при самой первой активации расширения (в данном случае при выполнении команды), и `deactivate`. Внутри функции `activate` вызывается `registerCommand`.
  * Функция с реализацией команды передается вторым параметром в `registerCommand`.

## Как это работает

1. Пользователь запускает команду из палитры команд.
2. Первая папка рабочего пространства берется как корень. Если папка не открыта, показывается ошибка "You have to open project firstly!".
3. В корень записывается пустой graph.md (файл начинается с заголовка Mermaid, `graph LR`).
4. `makeGraph` рекурсивно сканирует проект и добавляет в graph.md одну строку для каждого файла и директории.
5. В конец файла дописывается закрывающий "```" и показывается сообщение "Graph has been made successfully!".

## Функции

### isIgnore(name: string): boolean

Эта функция решает, игнорировать ли данный путь или нет.

Аргументы:

* `name` (string) - имя файла или директории

Возвращает:

* `is_ignored` (boolean) - true, если файл будет проигнорирован, и false, если нет

### makeGraph(root: string | undefined, graphpath: string, dirname: string | undefined): Promise\<void\>

Эта функция рекурсивно сканирует проект и, если файл или директория не должны игнорироваться,
добавляет файл или директорию в граф.

Аргументы:

* `root` (string | undefined) - полный путь к текущей родительской (корневой) директории.
* `graphpath` (string) - полный путь к graph.md.
* `dirname` (string | undefined) - имя текущей родительской (корневой) директории.

Возвращает:

* Promise\<void\> - промис, который выполняется после успешной записи в файл.

### activate(context: vscode.ExtensionContext)

Активирует расширение VS Code и регистрирует команду генерации графа.

Аргументы:

* `context` - контекст расширения, предоставляемый VS Code

### deactivate()

Деактивирует расширение VS Code.

## Формат выходного файла

graph.md - это Markdown файл с одним Mermaid блоком:

* первая строка ```` ```mermaid ````, вторая строка `graph LR`;
* каждая следующая строка - одна связь между родителем и потомком;
* последняя строка "```".

## Быстрый запуск

* Откройте любой проект в новом окне.
* Нажмите `Ctrl+Shift+P` для того, чтобы открыть палитру команд.
* Введите команду "Make graph".
* Откройте созданный файл `graph.md` и нажмите `Ctrl+Shift+V`.
* В новой вкладке откроется готовый граф.
